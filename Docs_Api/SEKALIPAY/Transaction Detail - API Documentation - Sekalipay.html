Transaction Detail

Dapatkan detail lengkap transaksi berdasarkan ref_id atau invoice. Response akan menyertakan data item, H2H results, dan SMM results sesuai jenis order.

GET /v1/trx/{'{ref_id}'}

Path Parameters

Parameter Type Description
ref_id string Reference ID atau Invoice transaksi.

analytics Response Fields

receipt Transaction Data

id integer

ID unik transaksi

ref_id string

Reference ID yang Anda kirim saat create order

invoice string

Invoice number dari sistem

payment_method string

Metode pembayaran: saldo, qris, dll

status string

Status transaksi: pending, paid, completed, failed

price integer

Harga produk (sebelum fee)

fees integer|null

Biaya transaksi (payment gateway fee)

amount integer

Total yang dibayar (price + fees − coupon_discount)

coupon_code string|null

Kode voucher yang dipakai. Order lewat API reseller selalu null — voucher hanya ada di checkout web & aplikasi.

coupon_discount integer

Potongan voucher dalam rupiah (0 bila tanpa voucher). Dipakai agar rincian tutup: price + fees − coupon_discount = amount.

note string|null

Catatan transaksi dari sistem

payment_link string|null

Link pembayaran (hanya untuk payment gateway)

qr_link string|null

Link QR Code (untuk QRIS)

expired_at datetime|null

Waktu kadaluarsa pembayaran

created_at datetime

Waktu transaksi dibuat

inventory_2 Items Array

variant_id integer

ID variant produk

variant_name string

Nama variant

product_name string

Nama produk

product_license string|null

Data produk (akun/lisensi) - hanya untuk auto

seller_note string|null

Catatan penjual untuk varian ini — biasanya instruksi pemakaian (cara login, larangan mengganti password, masa aktif). Berbeda antar varian pada produk yang sama, jadi ambil per item, bukan per produk. null bila varian tersebut memang tidak punya catatan. Berbeda dari note di bawah, yang menempel pada data pesanan.

price integer

Harga per item

qty integer

Jumlah item

note string|null

Customer data (nomor HP, link target, dll)

order_process string

Jenis proses: auto, manual, h2h, smm

sync_alt H2H Results (untuk order_process: h2h)

variant_id integer

ID variant yang diproses H2H

sn string

Serial Number dari provider. Jika failed: "failed: [error message]"

dispatch_status string

Status seluruh unit item ini: completed (semua unit terkirim), failed (semua gagal), partial (sebagian berhasil, sebagian gagal), atau pending (masih ada unit berjalan).

log_message string|null

Pesan dari provider

total_units / delivered_units / failed_units integer

Jumlah unit item ini, berapa yang sudah terkirim, dan berapa yang gagal. Untuk quantity: 1 nilainya selalu 1 / 0 atau 1 / 0.

units array

Rincian per unit: unit (urutan, mulai 1), dispatch_status, sn, ref_id, log_message. Order dengan quantity > 1 menghasilkan satu SN per unit — ambil semuanya dari sini; field sn di level atas hanya berisi SN pertama.

Penting untuk quantity > 1: satu unit = satu dispatch dengan SN sendiri. Jangan menutup order hanya karena ada SN yang muncul — order baru benar-benar selesai saat dispatch_status: "completed", atau saat delivered_units + failed_units == total_units.

thumb_up SMM Results (untuk order_process: smm)

variant_id integer

ID variant SMM

order_id string|null

ID order dari SMM Panel

status string

Pending, In progress, Completed, Partial

start_count integer|null

Jumlah awal sebelum diproses

remains integer|null

Sisa yang belum terkirim (0 = selesai)

provider_status string|null

Status mentah dari source SMM jika tersedia

delivered_count integer|null

Jumlah yang sudah berhasil diproses/dikirim

refund_amount integer|null

Nominal refund parsial jika ada

partial_refund_pending_manual boolean

Penanda jika refund parsial masih menunggu tindak lanjut manual
