Memulai

Indoapi adalah Payment API Gateway mandiri yang menghubungkan aplikasi Anda langsung ke akun GoPay Merchant pribadi Anda. Semua transaksi diproses secara real-time dan langsung masuk ke saldo akun Anda tanpa perantara.

Base URL https://indoapi.biz

Autentikasi

Seluruh pemanggilan REST API wajib menyertakan autentikasi menggunakan API Key. Anda dapat meletakkan API Key pada header HTTP request dengan format berikut:

X-API-Key: iak_xxxxxx
atau
Authorization: Bearer iak_xxxxxx

Buat Pembayaran

Meminta pembuatan invoice pembayaran baru. Server akan mengembalikan parameter string QRIS dinamis yang siap dipindai oleh pelanggan Anda.

POST https://indoapi.biz/api/v1/payment/create

Body Parameters (JSON)

Parameter Tipe Wajib Keterangan
amount Number Ya Jumlah nominal pembayaran dalam Rupiah (min. 1000).
reference String Tidak ID unik transaksi dari sistem Anda. Jika kosong, invoice ID generator default akan digunakan.
description String Tidak Keterangan/catatan pembayaran.
customer_name String Tidak Nama pelanggan Anda.
callback_url String (URL) Tidak URL webhook tujuan khusus untuk transaksi ini.
Contoh Request 
{
  "amount": 50000,
  "reference": "INV-10291",
  "description": "Beli Kaos Distro",
  "customer_name": "Anto"
}
Contoh Response (201 Created) 
{
  "success": true,
  "data": {
    "invoice": "INV-20260620-80E2",
    "reference": "INV-10291",
    "amount": 50000,
    "qris_string": "0002010102122657...",
    "qr_image": "https://api.qrserver.com/v1/create-qr-code/?size=250x250&data=000201...",
    "payment_url": "https://indoapi.biz/payment/status/INV-20260620-80E2",
    "status": "pending",
    "expired_at": "2026-06-21T15:00:00+07:00"
  }
}

Batal Transaksi

Membatalkan transaksi pembayaran pending. Status transaksi akan diubah menjadi failed.

POST https://indoapi.biz/api/v1/payment/cancel

Body Parameters (JSON)

Parameter Tipe Wajib Keterangan
reference String Ya* ID unik transaksi dari sistem Anda atau ID Invoice (misal: INV-xxxx). *Wajib mengisi salah satu dari reference atau invoice.
invoice String Ya* ID Invoice Indoapi (misal: INV-xxxx). *Wajib mengisi salah satu dari reference atau invoice.
Contoh Request 
{
  "reference": "INV-10291"
}
Contoh Response (200 OK) 
{
  "success": true,
  "message": "Transaksi berhasil dibatalkan",
  "data": {
    "invoice": "INV-20260620-80E2",
    "reference": "INV-10291",
    "status": "failed"
  }
}

Integrasi Webhook

Bila diaktifkan, server kami akan mengirimkan HTTP POST callback secara asinkron saat status pembayaran berubah menjadi success, failed, atau expired.

Payload Webhook 
{
  "event": "payment.updated",
  "invoice": "INV-20260620-80E2",
  "reference": "INV-10291",
  "amount": 50000,
  "status": "success",
  "payment_method": "qris",
  "paid_at": "2026-06-20 15:32:01",
  "timestamp": "2026-06-20T15:32:01+07:00",
  "signature": "c8e2fb8a9d012e..."
}

Verifikasi Signature

Untuk memastikan data webhook dikirim oleh Indoapi dan tidak dimodifikasi di tengah jalan, Anda wajib melakukan verifikasi signature. Signature dikirimkan di dalam JSON payload dengan parameter signature.

Signature dibuat dengan algoritma HMAC-SHA256 menggunakan Webhook Secret Key Anda sebagai kunci hashing, dari isi JSON payload (tanpa menyertakan parameter `signature` itu sendiri).

Contoh Verifikasi PHP 
$data = json_decode(file_get_contents('php://input'), true);
$signature = $data['signature'] ?? '';
unset($data['signature']);

$expectedSignature = hash_hmac('sha256', json_encode($data), $webhookSecret);

if (hash_equals($expectedSignature, $signature)) {
    // Valid request
}

Kode Error

Format response JSON standard untuk error adalah:

{
  "success": false,
  "message": "Pesan deskripsi kesalahan"
}
HTTP Code Keterangan
400 Bad Request Validasi input bermasalah (contoh: nominal tidak valid).
401 Unauthorized API Key tidak valid, dinonaktifkan, atau tidak disertakan.
403 Forbidden Akun belum berlangganan atau tidak memiliki wewenang akses.
404 Not Found Pembayaran tidak ditemukan.
